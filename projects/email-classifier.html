Infosys Springboard Virtual Internship 6.0

AI-Powered Smart Email Classifier for Enterprises

An NLP and machine-learning project to classify enterprise email and help prioritise messages by category and urgency.

PythonTF-IDFSVMDistilBERTFastAPI
Open GitHub repository ↗

Problem

Enterprise teams receive large volumes of email. Manually categorising each message and identifying urgent items can slow down communication and make it harder to prioritise work. This project explores an ML-based approach to email categorisation and urgency detection.

My role

I served as Team Lead for a 22-member team. I contributed across project modules, including backend work and FastAPI integration, while coordinating delivery within the virtual internship's Agile project structure.

Workflow and modules

  1. Data collection and preprocessing
  2. Email categorisation engine
  3. Urgency detection using machine-learning methods
  4. Dashboard and visualisation
  5. Deployment and integration

Model evaluation

The recorded evaluation compared Logistic Regression with TF-IDF, SVM with TF-IDF and a DistilBERT baseline.

92.89%Logistic Regression accuracyF1: 0.9282
94.45%SVM + TF-IDF accuracyF1: 0.9435
95.50%DistilBERT accuracyF1: 0.9552

DistilBERT produced the strongest recorded result among these baselines. The comparison should be interpreted alongside the exact dataset split, preprocessing, label distribution and evaluation code in the repository.

Technology

  • Python and common data-science tooling
  • TF-IDF text representation and traditional classifiers
  • DistilBERT baseline for contextual text representation
  • FastAPI for backend/API integration

What I learned

  • How to compare a traditional NLP baseline with a transformer model.
  • Why F1-score provides useful context alongside accuracy.
  • How team coordination, integration and model development intersect in a multi-module project.
