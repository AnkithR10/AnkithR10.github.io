# ANKITH — Portfolio

A responsive static portfolio built with HTML, CSS and JavaScript. It supports offline editing and GitHub Pages hosting.

## Pages
- `index.html` — Home, portrait and featured projects
- `projects.html` — Six selected GitHub projects
- `about.html` — Academic profile and skills
- `research.html` — Research summary
- `experience.html` — Internship, volunteering and leadership
- `contact.html` — Contact links

3. AI-Powered Smart Email Classifier for Enterprises
4. Predicting Depression Through Social Media Behaviour
5. Life Expectancy Clustering
6. Automated Dataset Cleaner

## Portrait and preview
The provided portrait is at `assets/ankith-profile.png`. Open `index.html` in a browser or use VS Code Live Server. The small reveal effects respect the operating system's reduced-motion setting.

## Publish on GitHub Pages
Push the site files to a public repository, then choose **Settings → Pages → Deploy from a branch → main → /(root)**. A user site can use the repository name `AnkithR10.github.io`. GitHub Pages hosts static files only; it does not run a FastAPI or MongoDB backend.

## Before publishing
- Add a résumé PDF only if you want to link one; do not link a missing file.
- Open each repository and verify the README, code and project status.
- Keep any performance metrics consistent with the final evaluation outputs.
